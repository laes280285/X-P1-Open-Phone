# Carcasa y mecanismo plegable

**Sin STEP/STL listos para producción.** La meta es publicar archivos editables FreeCAD/STEP/STL, detalles de bisagra, flexibles, tapas de batería/SSD, teclas, tolerancias y guías de ensamblaje.

La forma es idéntica en gris aluminio/plástico y negro con detalles naranjas. **LT/LB/RB/RT deben quedar atrás de la base inferior**, como en el New Nintendo 2DS XL.
