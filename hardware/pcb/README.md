# PCB portadora del X-P1

**Sin esquemáticos KiCad todavía.** Esta carpeta recibirá los archivos editables, revisiones de ingeniería, BOM con MPN, Gerbers, taladros y archivos de colocación. No fabricar basándose en diagramas de bloques o renders.

Prioridades: alimentación y seguridad de batería, buses CM5, módem 4G, NVMe, controles, radio FM, IR y audio cerrado/abierto.
