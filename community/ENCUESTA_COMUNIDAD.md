# Encuesta inicial para GitHub Discussions → Polls

**Title:** Would you actually build an X-P1? / ¿Armarías un X-P1 por tu cuenta?

**Poll question:** What total parts-and-manufacturing budget (including shipping, excluding your own labor) would make the X-P1 attractive for DIY assembly? / ¿Qué presupuesto total para piezas y fabricación te resultaría atractivo?

**Poll options (USD; indicative tiers for international participation):**

- Under $150 USD
- $150–249 USD
- $250–349 USD
- $350–499 USD
- $500 USD or more
- Interested in contributing but not building one

**Body:**

This is an early feasibility poll, not a product price or preorder. Please comment with your country, preferred platform (Linux/Android), whether you would build one, and which features are essential versus optional. The current design has not been costed or prototyped.

Encuesta para medir interés, **no** es una cotización ni preventa. Comenta tu país, si te gustaría ensamblarlo, qué sistema usarías y qué características son imprescindibles u opcionales.
