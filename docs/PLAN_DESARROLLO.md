# Plan de desarrollo colaborativo

| Etapa | Objetivo | Criterio de salida |
|---|---|---|
| 0. Viabilidad | Elegir módulos, datos de tamaño, coste y seguridad | Presupuesto y modelo CAD volumétrico |
| 1. Mesa de pruebas | CM5, módem LTE, pantalla, audio, batería segura | Demostración real de llamadas/SMS/datos |
| 2. UX cerrado / abierto | E-Paper, micrófono exterior, teclado, gatillos y sticks | Responder cerrado y jugar abierto |
| 3. Diseño para fabricar | PCB KiCad, flex de bisagra, chasis CAD, térmico | Revisión eléctrica/mecánica independiente |
| 4. Primer equipo integrado | PCBA y carcasa de prueba | Pruebas térmicas, RF, audio y autonomía |
| 5. Guía reproducible | BOM, Gerbers, archivos CAD, firmware e instrucciones | Ensamblaje independiente documentado |

Este repositorio solicita **colaboración técnica y opiniones**, no preventas ni aportaciones económicas. La selección de componentes y el presupuesto deben respaldarse con cotizaciones, no con precios estimados de renders.
