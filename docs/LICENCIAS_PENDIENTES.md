# Licencias — decisión abierta

Todavía no se ha seleccionado una licencia definitiva para diseños mecánicos, PCB, firmware o documentación. La intención es permitir proyectos comunitarios reproducibles, respetando derechos y licencias de terceros.

Candidatas para discusión:
- Hardware/CAD/PCB: CERN-OHL-P-2.0 o CERN-OHL-S-2.0.
- Software y firmware propio: MIT o Apache-2.0.
- Documentación: CC BY 4.0 o CC BY-SA 4.0.
- Marca X-P1 y renders de concepto: condiciones de uso y atribución por definir.

**No interpretar el material presente como producto certificado, diseños finalizados ni cesión de derechos sin licencia.** Elegir las licencias antes de aceptar contribuciones técnicas significativas.
